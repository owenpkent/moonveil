# Security Policy

Any security vulnerability discovered in Moonveil will be fixed as soon as possible with as minimal impact as possible when reported.

Please ensure you are always running the [latest version available](https://github.com/owenpkent/moonveil/releases).

Some web browser extension stores may have an older version currently published.

## Security Vulnerability Report

If you have discovered a security vulnerability, please report it privately through GitHub's [private vulnerability reporting](https://github.com/owenpkent/moonveil/security/advisories/new).

Do not open a public issue for security vulnerabilities. Private reporting lets us investigate and prepare a fix before details are public.
